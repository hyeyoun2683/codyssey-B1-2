# VOLT Energy Drink
# 1. 브랜드 아이덴티티
## 1-1. 브랜드명

VOLT

## 1-2. 브랜드 소개

VOLT는 지치고 집중력이 떨어지는 순간에도 다시 시작할 수 있도록 에너지를 전달하는 가상의 에너지 드링크 브랜드이다.

## 1-3. 타겟

학업, 과제, 시험 및 자기계발 등으로 늦은 시간까지 집중해야 하는 대학생 및 20대 청년층

## 1-4. 브랜드 톤앤매너
어둡고 세련된 분위기
강렬하고 역동적인 이미지
딥 네이비와 일렉트릭 블루 중심의 색감
미래지향적이고 현대적인 느낌
에너지와 집중력을 시각적으로 표현
## 1-5. USP

지친 순간 다시 집중할 수 있도록 에너지를 전달하는 제품

## 1-6. 브랜드 슬로건

“멈추지 말고, 다시 시작해.”

# 2. 캠페인 기획
## 2-1. 캠페인 목적

늦은 시간까지 공부하거나 과제를 수행하며 지친 대학생에게 VOLT를 통해 다시 집중하고 시작할 수 있다는 메시지를 전달하여 브랜드 인지도를 형성하는 것을 목적으로 한다.

## 2-2. 핵심 메시지

“지쳤다고 멈추지 말고, VOLT와 함께 다시 시작하자.”

## 2-3. 광고 콘셉트

「RESTART YOUR ENERGY」

늦은 밤 공부에 지친 대학생이 VOLT를 마신 후 다시 집중력을 되찾는 과정을 짧은 영상으로 표현한다.

광고는 문제 제시 → 제품 등장 → 에너지 전환 → 브랜드 메시지의 4단계 구조로 구성하였다.

14. 제작 과정에서 발생한 문제 및 해결 방법
문제 1. AI 이미지의 텍스트 오류

제품 이미지 생성 과정에서 VOLT라는 브랜드명이 왜곡되거나 한글 문구가 정확하게 표현되지 않는 문제가 발생하였다.

해결 방법

텍스트의 내용과 위치를 프롬프트에 구체적으로 명시하고, 불필요한 텍스트가 생성되지 않도록 조건을 추가하였다.

문제 2. 캐릭터 및 분위기 일관성

각 씬을 별도로 생성하면서 인물의 외형이나 분위기가 완전히 동일하게 유지되지 않을 가능성이 있었다.

해결 방법

각 씬의 프롬프트에서 젊은 한국인 대학생, 어두운 야간 공부 공간, 검정/네이비 계열 의상, 일렉트릭 블루 조명 등의 공통 요소를 반복적으로 지정하여 시각적 일관성을 유지하였다.

문제 3. 영상 생성 크레딧 및 생성 실패 가능성

영상 생성 AI는 이미지 생성보다 크레딧 소모량이 많고 원하는 결과가 나오지 않을 경우 재생성 비용이 발생할 수 있다.

해결 방법

먼저 이미지 단계에서 전체적인 장면과 스타일을 확정한 후 Sora 2를 이용해 영상으로 변환하였다. 또한 최종 광고를 4개의 씬으로 단순화하여 불필요한 재생성을 줄였다.

문제 4. 영상 길이 제한

과제의 최종 영상 길이는 10초 이내여야 한다.

해결 방법

각 씬의 길이를 약 2.4~2.5초로 조정하여 최종 영상 길이를 약 9.64초로 구성하였다.

15. 최종 결과 및 기대 효과

이번 광고는 “지쳤다고 멈추지 말고, 다시 시작하자”라는 메시지를 중심으로 구성하였다.

늦은 밤 공부에 지친 대학생을 등장시켜 타겟의 공감대를 형성하고, VOLT의 등장과 함께 일렉트릭 블루 에너지를 활용하여 상황이 전환되는 모습을 표현하였다.

마지막에는 VOLT 브랜드명과 “멈추지 말고, 다시 시작해.”라는 슬로건을 노출하여 짧은 영상에서도 브랜드와 핵심 메시지가 기억될 수 있도록 제작하였다.

또한 이미지 생성 AI, 영상 생성 AI, 음성 생성 AI를 각각 활용하고 CapCut을 통해 결과물을 통합함으로써 기획 → 프롬프트 → 생성 → 수정 → 통합 편집 → 최종 영상 출력으로 이어지는 AI 기반 멀티모달 제작 파이프라인을 직접 경험하였다.
